# هّمة — نحو يوم أفضل

نظام شخصي لإدارة اليوم والحياة: مهام، جدول، أهداف، عادات، تركيز، XP ومستويات، تحديات، مكافآت، إحصائيات، ومساعد ذكي — بواجهة عربية مستقبلية (Dark · Glass · Neon).

🔗 **الموقع:** https://misharym373-droid.github.io/Himmah/

## المزايا
- **إدخال طبيعي بالعربي:** اكتب أو قل "عندي مذاكرة تفاضل الساعة 8 لمدة ساعة، وبعدها النادي الساعة 10" ويتحول لمهام مجدولة.
- **إضافة بالصوت** (Web Speech API) و**من صورة** (OCR عبر Tesseract.js يُحمّل عند الحاجة).
- **خريطة اليوم** بالسحب والإفلات وإعادة حساب الأوقات تلقائيًا، وجدول يوم/أسبوع/شهر.
- **وش أسوي الآن؟ · أنقذ يومي · عندي ساعة فقط · إعادة التخطيط** للمهام غير المنجزة.
- **وضع التركيز** بمؤقت كامل، XP ومستويات وLevel Up، Streak، إنجازات سرية، تحديات، متجر مكافآت.
- **الأهداف** تُقسّم تلقائيًا: طويل المدى ← شهري ← أسبوعي ← مهام يومية.
- **العادات** مع Heatmap ونسبة الالتزام، **توازن الحياة**، **آلة الزمن**، **مشاريع مشتركة**.
- **مساعد هّمة** بأربع شخصيات، قائمة أوامر (Ctrl+K)، اختصارات لوحة المفاتيح، مركز إشعارات، سلة محذوفات مع تراجع.
- **تخصيص كامل:** ليلي/نهاري/تلقائي، 5 ألوان، حجم الواجهة، الأنيميشن، الخلفية، وترتيب بطاقات الرئيسية.

## ملاحظات تقنية
- React + Vite + Zustand، بدون مكتبات ثقيلة (الرسوم البيانية SVG مخصصة).
- البيانات تُحفظ على جهاز المستخدم (LocalStorage) عبر طبقة تخزين قابلة للاستبدال بـ Backend (`src/lib/storage.js`).
- الحسابات محلية وكلمات المرور مشفّرة بـ PBKDF2-SHA256 (`src/lib/auth.js`). لربط نظام Auth حقيقي استبدل دوال هذا الملف.
- المساعد يعمل بمنطق محلي ذكي (`src/lib/assistant.js`) ولا يدّعي استخدام AI خارجي؛ دالة `chat()` جاهزة للاستبدال باستدعاء API.
- رابط **صُرّة** يُضبط من الإعدادات ← الحساب، أو من `src/config.js`.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## النشر
كل Push على `main` يبني الموقع وينشره تلقائيًا على فرع `gh-pages` (انظر `.github/workflows/deploy.yml`).
لربط دومين خاص مثل `himmah.com` أضف ملف `public/CNAME` يحتوي اسم الدومين.
